STACKING AMMO 2.0
GitHub 저장소의 최상위(root)에 다음 7개 파일을 올리세요:
index.html / admin.html / style.css / admin.css / app.js / admin.js / firebase-config.js

기존 index.html은 새 index.html로 교체하세요.
GitHub Pages는 기존 main / root 설정을 유지하세요.
관리자 페이지 주소: 기존 홈페이지 주소 뒤에 /admin.html

관리자에서 가능한 것:
- 게시글 작성/수정/삭제
- English / Investing 분류
- 사이트 제목, 소개, 상단 문구 변경
- 배경색, 포인트색, 글자색, 모서리 스타일 변경

관리자 비밀번호는 코드에 넣지 마세요.
